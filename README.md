# Zenith ⚡ - Yaşam & Görev Yönetim Sistemi

**Zenith**, günlük işlerinizi, alışkanlıklarınızı ve odaklanma sürelerinizi oyunlaştırarak yönetmenizi sağlayan modern, hızlı ve duyarlı bir web uygulamasıdır.

🔗 **Canlı Demo / Geliştirici:** [an1lbayram](https://an1lbayram-github-io.vercel.app/)

---

## 🌟 Öne Çıkan Özellikler

- 📋 **Görev Yönetimi (Kanban Board)**: Yapılacaklar, Devam Edenler ve Tamamlananlar sütunları, kategori filtreleri, arama çubuğu ve alt görevler (checklist).
- 🌱 **Alışkanlık Takibi (Habit Tracker)**: Günlük seriler (Streak 🔥), 7 günlük hızlı takvim görünümü ve günlük XP kazanımı.
- 🧘 **Odak Modu (Pomodoro Timer)**: 25 Dk Odaklanma, 5 Dk Kısa Mola ve 15 Dk Uzun Mola modları, Web Audio API sentezlenmiş ses uyarıları.
- 👑 **Oyunlaştırma & Seviye Sistemi**: Tamamlanan görev ve alışkanlıklarla XP kazanın, seviye atlayın ve özel başarı rozetleri (Achievements) açın.
- 📊 **Aktivite Haritası & Analitik**: GitHub tarzı 12 haftalık gerçek aktivite haritası ve kategori dağılım grafikleri.
- 🎨 **Dinamik Temalar & Dark Mode**: Emerald, Blue, Purple, Red ve Amber renk paletleri, tam karanlık mod desteği.
- 📱 **Progressive Web App (PWA)**: Çevrimdışı (Offline) çalışma desteği, mobil yükleme uyumluluğu.
- 💾 **Veri Yedekleme**: Tüm verileri JSON formatında dışa aktarma (Export) ve içeri aktarma (Import).

## 🚀 GitHub & Vercel'e Yükleme Rehberi

### GitHub'a Yükleme
```bash
git init
git add .
git commit -m "Initial commit - Zenith"
git branch -M main
git remote add origin https://github.com/KULLANICI_ADI/zenith.git
git push -u origin main
```

### Vercel'e Dağıtım (Deploy)
1. [Vercel](https://vercel.com) hesabınıza giriş yapın.
2. **"Add New Project"** butonuna tıklayın ve GitHub kulübünüzdeki `zenith` reposunu seçin.
3. Build Settings varsayılan ayarlarda kalsın (Framework Preset: Other / Static HTML).
4. **"Deploy"** butonuna basın. Projeniz saniyeler içinde canlıya alınacaktır!
